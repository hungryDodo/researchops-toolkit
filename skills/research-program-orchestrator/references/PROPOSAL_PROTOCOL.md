# Capability proposal protocol

A proposal is a reversible advisory record, not an invocation and not approval.

## When to scan

Run the lightweight advisor only at meaningful hinges:

- lifecycle stage transition;
- before hardware, destructive, publication-decision, external-provider, or high-cost work;
- when the dashboard shows an overdue gate or unresolved evidence blocker;
- when a user asks for a plan that clearly reaches one of those actions.

Do not scan every sentence or atomic edit.

## Proposal fields

- capability and target skill/mode;
- trigger evidence from the planned action/state;
- benefit and risk reduced;
- expected context/cost;
- required approval and prerequisites;
- status: recommended, approved, dismissed, snoozed, completed;
- dedupe key and expiry stage.

Approval permits the orchestrator to invoke the named specialist. It never authorizes the specialist's own destructive or hardware action; that action keeps its native approval gate.
