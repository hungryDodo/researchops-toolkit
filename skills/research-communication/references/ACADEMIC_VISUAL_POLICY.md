# Academic visual policy

This is a static, reusable design contract. It does not require an existing website or design input.

- Optimize for comprehension at final publication or projection size.
- Use semantic hierarchy: question → mechanism → evidence → limitation.
- One primary visual signature per artifact; avoid decorative themes.
- Use restrained, color-blind-safe palettes and redundant non-color encodings.
- Figures: vector export where possible, honest axes, legible post-scaling text, direct labels, self-contained captions.
- Slides: one main claim per slide, large type, sparse prose, evidence/source visible, appendix for depth.
- Accessibility: sufficient contrast, no color-only state, reduced motion for HTML, keyboard-readable structure.
- Academic neutrality: do not imitate a commercial brand unless explicitly requested for a non-academic artifact.
