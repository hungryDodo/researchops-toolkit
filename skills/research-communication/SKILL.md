# Research Communication

## Trigger contract

Own external academic visuals: paper figures and presentations. The operational dashboard is a shared component updated by the orchestrator, not a user-facing design Skill.

## Progressive loading

- `figure` mode: `references/FIGURE_PROTOCOL.md` and `references/ACADEMIC_VISUAL_POLICY.md`;
- `presentation` mode: `references/PRESENTATION_PROTOCOL.md` and `references/ACADEMIC_VISUAL_POLICY.md`.

## Design position

No website or prior design input is required. Distill-design's URL→DESIGN.md workflow is intentionally **not** part of the normal path because the goal is clear, accessible, academically conventional communication—not brand imitation. We retain only the useful idea of a compact reusable design contract, implemented as a static academic visual policy.

## Figure mode

Classify motivated example, system/method overview, experimental result, or supporting figure. Choose a truthful paradigm, concrete layout, semantic labels, appropriate tool, vector export, post-scaling font size, color-blind-safe encoding, honest axes, and a self-contained caption. Audit an existing image when provided.

## Presentation mode

Choose audience and purpose, define one takeaway per slide, build a narrative from problem through evidence and limitations, use verified figures, and keep appendix depth proportional to likely questions.

## Output contract

Produce visual intent, narrative role, layout/slide plan, data and claim sources, tool/export choice, accessibility and integrity audit, and editable artifact requirements.
