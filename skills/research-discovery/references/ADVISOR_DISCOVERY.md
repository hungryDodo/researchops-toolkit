# Advisor-grade discovery patterns

Design-pattern adaptation informed by Supervisor-Skills and other research-assistant systems.

## Freeze before search

Write 2–3 answerable research questions, scope, exclusions, target reader, date range, and what evidence would change the decision. Do not let interesting papers silently redefine the question.

## Search perspectives

Run independent query families for:

1. canonical/mainstream approaches;
2. closest mechanism and terminology variants;
3. negative results, limitations, replications, and critiques;
4. adjacent fields that solve the same bottleneck differently;
5. evaluation methodology, datasets, metrics, and confounders;
6. deployment/resource constraints relevant to the actual project.

Use clean-context workers for independent perspectives when available. They return source paths/citations, uncertainty, and a short synthesis rather than flooding the parent context.

## Evidence status

- `retrieved-and-verified`: primary source loaded and the cited detail checked;
- `retrieved-unverified`: metadata found, method/result detail not yet checked;
- `model-recalled-unverified`: search lead only;
- `user-provided`: provenance preserved; verification status still explicit.

Model memory and search snippets never support specific authors, numbers, mechanisms, or novelty claims.

## Novelty discipline

A search miss means only “not retrieved under these queries.” Compare closest work along object, mechanism, granularity, setting, assumptions, evidence, and deployment constraints. End with unresolved collision risk and queries still worth running.

## Synthesis

Answer each frozen research question directly. Organize by mechanism/tension rather than one-paper-per-paragraph summaries. Separate consensus, disagreement, missing evidence, and project-relevant implications.
