# Provider onboarding

1. Verify current official provider documentation outside this static package.
2. Add a non-secret execution-arm declaration under project governance.
3. Put credentials in the local user secret file or environment by variable name only.
4. Run registry sync and doctor.
5. Run a bounded probe; record endpoint/identity telemetry and never competence.
6. Run an Anchor or low-risk Shadow work unit before normal routing.
7. Inspect cost, endpoint health, disclosure boundary and model identity.
8. Enable the arm with a suitable risk ceiling.

A provider may preserve one public model ID while changing hidden behavior. Use deployment epochs and observed drift; do not claim a hidden cause that cannot be verified.
