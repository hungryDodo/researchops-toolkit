# Revision protocol

Prefer small coherent patches over wholesale rewriting. Use the repository’s build system first. Keep generated files out of version control unless the project deliberately tracks them.

For visual QA inspect: overfull/underfull boxes, clipped content, float placement, font size, single-column readability, table alignment, citation/reference resolution, equation numbering, and accessibility descriptions when required.

If feedback would require new evidence, mark it blocked and route to experiment design/execution rather than polishing unsupported prose.
