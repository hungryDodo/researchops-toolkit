# Evidence-gated writing protocol

## Evidence hierarchy

1. project artifacts and approved analyses;
2. primary literature opened and verified for the exact statement;
3. user-provided authoritative material with provenance;
4. field-common background that does not contain fragile names, numbers, priority, or comparisons.

Model memory and unverified search snippets may suggest what to verify, but may not become manuscript evidence.

## Claim language ladder

- `we measure / observe`: direct result under named conditions;
- `our profiling indicates / is consistent with`: mechanism evidence with remaining alternatives;
- `improves`: requires a specified comparator, workload, metric, and uncertainty;
- `causes`: requires a valid causal intervention or design;
- `generalizes`: requires justified domains beyond the development setting;
- `first / novel / unlike prior work`: requires a current closest-work search and calibrated wording.

Never upgrade language to make the story smoother.

## Draft sequence

1. Build a claim map before prose.
2. Mark each claim as established, bounded, exploratory, planned, or unsupported.
3. Draft the logical bridge from problem → gap → mechanism → evidence → limitation.
4. Insert citations only after the exact source support is checked.
5. Run a fresh-context consistency pass for numbers, baselines, definitions, and figure/table references.
6. Keep unsupported scientific gaps outside the manuscript as explicit actions.

## Authorship boundary

The Agent may propose structure and language, but must not invent decisions, motivations, results, citations, or author beliefs. Meaning-changing revisions are surfaced for author confirmation.
